Nike Air Max 90

Do layout no Figma à interface em React

Sobre o projeto

Reprodução de uma página de produto a partir de um layout no Figma, com destaque para o tênis, componentes em React, layout responsivo e animações em CSS.

Do design ao código

Estudo de desenvolvimento frontend voltado à reprodução de uma tela de produto a partir de um layout no Figma. A interface organiza a navegação, as informações do produto e a imagem do tênis em componentes React com TypeScript. O CSS define a composição visual, a tipografia, os estados de hover e uma animação de flutuação do produto. O layout se adapta a telas menores e respeita a preferência por movimento reduzido. O Vite é usado no ambiente de desenvolvimento e na geração da versão publicada no GitHub Pages.

Habilidades aplicadas
