Sobre o projeto

Página de aprendizagem sobre a jornada B2B móvel, com vídeos, conteúdos interativos e efeitos de rolagem que conduzem a exploração do material.

Aprendizagem em uma jornada visual

Desenvolvimento de uma experiência de aprendizagem em página única sobre a jornada do cliente B2B e as soluções móveis. O conteúdo combina vídeos do Vimeo, navegação por seções, janelas de detalhes e elementos interativos. HTML, CSS e JavaScript estruturam a interface, com efeitos de parallax que criam profundidade durante a rolagem. O projeto inclui um pacote SCORM 1.2 e rotinas de comunicação com LMS para status e pontuação. A demonstração no GitHub Pages permite explorar o material fora de uma plataforma de aprendizagem.
