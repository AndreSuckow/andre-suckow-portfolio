Transformação digital para negócios

Sobre o projeto

Experiência de aprendizagem sobre transformação digital e segurança nos negócios, com carrosséis, abas e painéis interativos para explorar o conteúdo.

Conteúdo que convida à exploração

Desenvolvimento de uma página de aprendizagem para o projeto Torre Cloud Google Workspace, com conteúdo sobre transformação digital, seus desafios e segurança nos negócios. A interface organiza as informações em carrosséis, abas e painéis expansíveis, utilizando componentes React e estilos em CSS. O projeto é escrito em JavaScript e utiliza Vite para desenvolvimento e build. A estrutura SCORM 1.2, com o wrapper Pipwerks, oferece comunicação com plataformas LMS para informações do participante, pontuação e conclusão. A demonstração está disponível no GitHub Pages.
