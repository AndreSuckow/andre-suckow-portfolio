Tabuleiro VIVO

Trilha interativa de aprendizagem

Sobre o projeto

Trilha visual com 18 conteúdos de aprendizagem. Cada casa abre uma janela com a descrição do curso e seu link de acesso, quando disponível.

Como funciona

O tabuleiro organiza 18 conteúdos em uma trilha visual. Ao selecionar uma casa, a interface apresenta o título, a descrição e o acesso ao curso, quando disponível. A implementação utiliza HTML, CSS e JavaScript, com áreas interativas sobre a arte do tabuleiro e janelas de detalhes. O projeto inclui configuração SCORM para comunicação com plataformas LMS; no GitHub Pages, a navegação funciona sem conexão a um LMS.
