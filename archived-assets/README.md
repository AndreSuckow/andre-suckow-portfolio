# Originais fora da publicação

`models/xadrez/` preserva o modelo original de Leandro Calazans, seus binários, texturas e licença CC BY 4.0. Ele não é usado pelo jogo atual, que usa `public/board-games/xadrez.js`, `public/vendor/chess.js` e elementos HTML.

Esta pasta fica fora de `public/` e não é copiada para `dist/`. Os arquivos foram movidos sem alteração de conteúdo. A licença acompanha o modelo; os créditos permanecem em `CREDITS.md`.
